SOACS GridWatch Professional v2.5 Dashboard Metrics

Changes:
- Main window opens maximized by default so Response / Next / Uptime / Manual columns remain visible.
- History column renamed to UPTIME.
- UPTIME shows success percentage based on successful checks divided by total checks.
- Response column now shows measured/actual results:
  * ICMP: 18 ms, Timeout, HostUnreachable, etc.
  * TCP: Connected (12 ms), Refused, Timeout, Port required.
  * UDP: Received, No Reply, Port required.
- Manual checks and scheduled checks both update uptime metrics.
- Existing SPIF branding, splash screen, summary mode, and details/log layout retained.
