SOACS GridWatch Professional v2.3

GUI Freeze / SPIF Theme Polish Build

Changes:
- Monitor/Profile dropdowns now use dark SPIF styling instead of white Windows controls.
- Dropdown closed state blends into the target grid row.
- Port field is directly editable from the grid for TCP/UDP.
- ICMP port field shows an em dash and is disabled.
- Next column now uses an active scanner/indeterminate bar instead of a stuck solid progress bar.
- Next text now shows SCANNING / CHECKING / OFF.
- Selected/hovered rows use cyan/green SPIF-style highlighting.
- About/version text updated to v2.3.

Target platform:
- Visual Studio 2019
- .NET Framework 4.8
- WPF
- No NuGet dependencies
