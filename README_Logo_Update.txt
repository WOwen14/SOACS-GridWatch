SOACS GridWatch Logo Update Instructions

Branding assets are stored in the Assets folder.

Files:
- Assets\Logo.png        Full application/about logo
- Assets\HeaderLogo.png  Compact header/summary logo
- Assets\SplashLogo.png  Splash screen logo
- Assets\AppIcon.ico     Window/taskbar icon

To update the logo:
1. Replace the image file with a new file using the same name.
2. In Visual Studio, confirm the file Build Action is Resource.
3. Rebuild the Release configuration.

Keep filenames unchanged to avoid code/XAML changes.
